# Course Task Manager

A small Python project for demonstrating project structure, Git, and GitHub.

## Project structure

```text
course-task-manager/
├── src/
│   └── task_manager/
│       ├── __init__.py
│       ├── task.py
│       └── app.py
├── tests/
├── README.md
├── requirements.txt
└── .gitignore
```

## Run the application

From the project root:

```bash
python -m src.task_manager.app
```

Expected output:

```text
Course tasks
------------
[x] Read the Git chapter
[ ] Create the first commit
[ ] Push the project to GitHub
```

## Install dependencies

The project currently uses only Python's standard library:

```bash
python -m pip install -r requirements.txt
```
